# 企业邮箱

整个文件夹可以复制到任意电脑、任意位置。里面没有本机路径，也不保存邮箱文件夹。换电脑后双击一次，填写那台电脑要使用的邮箱和授权码。

## 员工

双击 **开始使用.bat**。

第一次会问两项：

1. 企业邮箱地址
2. 授权码。这不是网页登录密码，由管理员单独提供。输入时屏幕不显示字符。

连接成功后：

- 输入 `1` 看最近 10 封邮件，再输入序号看正文
- 输入 `2` 写信。先显示收件人、主题和正文，输入 `是` 才真正发送
- 输入 `3` 更换账号
- 输入 `0` 退出

这台电脑没有 Python 时，窗口会直接说明，不会进入菜单。

## 智能体

在本目录运行 `python mail.py`。命令和参数见 `AGENTS.md`。

复制项目时不要复制 `.env`。一份文件夹只保存一个账号。
